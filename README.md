# 机甲防线 MECHA FRONTLINE

单文件、零依赖的网页塔防游戏。融合高达 / 全金属狂潮 / 新世纪福音战士的机甲题材，
玩法参考 **Tower Madness**（开放地形迷宫塔防）与 **Thronefall**（可亲自操纵的指挥单位）。

![游戏截图](screenshot.png)

## 美术：45° 立体战场

游戏内置一个**微型软件 3D 渲染器**（约 100 行，无任何第三方库）：

- 45° 等距（isometric 2:1）投影的 2.5D 战场，屏幕坐标 ↔ 世界坐标可逆换算（点击、部署、WASD 均按屏幕方向）；
- 所有敌我机体都是**真 3D 盒体模型**：绕 Z 轴自由旋转（炮塔转向目标）、平行光平面着色、背面剔除、画家算法深度排序；
- 使徒 Boss 为悬浮旋转的**正八面体**（雷天使式）多面体模型，带 AT 力场光环；
- 地面阴影、悬浮起伏、旋翼/浮游炮环绕动画、抛物线榴弹弹道、光束/粒子特效均按 3D 世界坐标投影。

## 怎么玩

直接用浏览器打开 `index.html` 即可，无需安装任何东西（纯 HTML5 Canvas + WebAudio）。

## 核心玩法

- **迷宫塔防（Tower Madness 式）**：地图没有固定道路。你部署的机体本身就是墙，
  地面敌军会实时寻路绕行——用炮塔修出蛇形迷宫来拖延敌人。系统会阻止你把路完全堵死；
  飞行单位（无人机、武装直升机）无视地形直线突进，必须保留对空火力。
  第 7 波起顶部开放第二入侵口。
- **亲自驾驶指挥机（Thronefall 式）**：用 `WASD`/方向键驾驶白色指挥机在战场机动，
  自动开火，`E` 释放光束回旋斩（范围伤害）。点击指挥机可花钱强化；被击坠后 8 秒重生。
- **20 波敌袭**，第 5/10/15/18/20 波出现使徒级 Boss：AT 力场（会再生的护盾）+ 重装甲，
  最终波为「使徒·雷天使」（蓝色正八面体）。

## 可部署机体

| 机体 | 造价 | 特点 |
| --- | --- | --- |
| 量产型MS·吉姆改 | 100 | 高射速机枪，杂鱼收割 + 便宜的迷宫墙 |
| 狙击AS·野蛮人改 | 180 | 超远程高伤，**完全穿甲**，克重装 |
| 浮游炮·感应终端 | 260 | 同时锁定 3 个目标的光束，50% 穿甲 |
| 重炮型·钢坦克II | 220 | 范围溅射，克密集地面编队，**无法对空** |
| AT力场干扰塔 | 150 | 范围减速（含飞行，Boss 减半），无伤害 |
| EVA初号机 | 550 | 高伤光束，15% 几率**暴走**造成 3 倍伤害 |

所有机体可升 3 级，出售返还 70% 投资。敌人有装甲值（直接减伤），光束/狙击类武器可穿透。

## 操作一览

| 按键 | 功能 |
| --- | --- |
| `1`–`6` | 选择机体 · 左键部署/选中 · 右键/`Esc` 取消 |
| `WASD` / 方向键 | 驾驶指挥机 |
| `E` | 光束回旋斩 |
| `空格` | 出击下一波 |
| `P` | 暂停 · 顶栏可切换 1x/2x/3x 速度与音效 |
